# AI-Powered RAG Chatbot for CSV Data

An intelligent Retrieval-Augmented Generation (RAG) chatbot that enables users to interact with CSV datasets using natural language. Built with LangChain, OpenAI Embeddings, FAISS, and Streamlit, the application retrieves relevant information from structured data and generates accurate, context-aware responses.

## Features

* Upload and process CSV datasets
* Semantic search using OpenAI Embeddings
* Fast vector similarity search with FAISS
* Context-aware question answering with LangChain
* Interactive Streamlit user interface
* Efficient retrieval pipeline for large datasets
* Scalable architecture for enterprise knowledge bases

## Tech Stack

* Python
* LangChain
* OpenAI API
* FAISS Vector Database
* Streamlit
* Pandas

## How It Works

1. Load CSV data into LangChain documents.
2. Generate embeddings using OpenAI Embeddings.
3. Store vectors in FAISS for efficient retrieval.
4. Retrieve relevant records based on user queries.
5. Use an LLM to generate concise, context-aware answers.

## Use Cases

* Business Intelligence
* Customer Support Knowledge Bases
* Data Exploration
* Internal Documentation Search
* Research and Analytics

This project demonstrates the practical implementation of Retrieval-Augmented Generation (RAG) for transforming structured datasets into an intelligent conversational experience.
